CPECLUB_C Engineering Projects
This repository contains my solutions for the computer engineering introductory C programming tasks.

For the week one project

Cramer's Rule Solver (Linear_Algebra/): This program solves a system of linear equations using Cramer's Rule.
How it works: It takes the coefficients of a 2x2 matrix and calculates the determinant to find the values of X and Y.
To run it: Compile using gcc solver.c -o solver and run with ./solver.
Mini Calculator (Calculator/) A simple command-line calculator that performs basic arithmetic.
How it works: It prompts the user for two numbers and an operator (+, -, *, /). It includes an edge-case check to prevent division by zero.
To run it: Compile using gcc calculator.c -o calculator and run with ./calculator.
Even/Odd Logic Gate (Even_Odd/) A concise program that classifies integers.
How it works: It utilizes the modulo operator (%) to determine if a number has a remainder when divided by 2.
To run it: Compile using gcc even_odd.c -o even_odd and run with ./even_odd.
